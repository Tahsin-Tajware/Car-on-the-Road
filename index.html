A Car in
the Road

A real-time scene rendered with Three.js. The road surface, the car paint, the sky and the roadside grass are each drawn by shaders written for this project in GLSL, lit by a moving sun and a lamp that circles the loop.

How this scene is built

A.S.M. Tahsin Tajware 20220104006  ·  Sonod Sadman 20220104025
Every object is modelled from Three.js geometry primitives and every texture is drawn at load time onto a canvas, so the project has no imported models and no downloaded image files. Each row points at the section of the source that answers a requirement.
